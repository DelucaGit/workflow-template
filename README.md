# workflow-template

Gemensamma arbetsregler för alla projekt: hur vi använder GitHub (epics, stories, tasks, labels, board, sprintar, PR:er och releaser).

Det här repot är den enda källan till sanning. Reglerna samlas i `WORKFLOW.md`, och labels, mallar och setup-skript ligger här så att varje nytt projekt får exakt samma mönster.

Arbetet med repot själv följs som tasks under [Issues](../../issues).
